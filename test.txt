## 1. What is Version Control and Why is it Important?

Version control is a system that keeps track of changes made to files, especially source code, over time. It allows developers to record every modification, view previous versions, and restore older versions if needed.

Importance:
- Maintains a complete history of changes.
- Makes collaboration easier for multiple developers.
- Prevents accidental loss of code.
- Helps identify who made specific changes and when.
- Makes it easier to fix bugs by reverting to a stable version.

## 2. Why Do Developers Use Git?

Git is a distributed version control system that helps developers manage and track changes efficiently.

Developers use Git because it:
- Tracks every code change.
- Supports teamwork without overwriting each other's work.
- Allows creating branches for new features or bug fixes.
- Makes merging code changes simple.
- Enables working offline and syncing changes later.

## 3. Common Problems Git Solves

Git helps solve several common development problems:
- Prevents code from being accidentally overwritten.
- Keeps a history of all changes.
- Allows developers to recover deleted or broken code.
- Simplifies collaboration among team members.
- Helps resolve conflicts when multiple people edit the same file.
- Makes releasing and maintaining software easier.
